# LinkedIn Post Studio

Build a dashboard where I can draft text posts, preview them, and click a 'Publish to LinkedIn' button to post them directly to my feed using our connection.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://anzars-linkedin-dashboard.lovable.app
